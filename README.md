# SteelHacks2026
Game made for 2026 Steel Hacks

## Link to Game
https://danielgallagher.itch.io/the-ice-cold-caf

## Inspiration
Our inspiration came from when we were working on another game for a larger project. In that project we were using Unity's particle systems and I thought it would look really good for a snowy game.

## What it does
In our game your are a snowman running your Café. In doing so you must get the orders for everyone while they run around. There are 4 food options and 2 drink options. If you take too long on getting the orders for them their mood will decrease. If their mood drops too far they'll get mad and start chasing you. Try to keep the average mood above 60% or at the end of the day you'll be closed.

## Controls
WASD to move
Left Mouse to Interact

## How we built it
We used Unity and C# to code and make this game.

## Challenges we ran into
About halfway through we pivoted our idea a little bit and that took some extra work to change.
